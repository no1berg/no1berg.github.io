# Sebastian L. Berg - Personal Portfolio Website

This repository contains the source code for my personal portfolio website, which showcases my research, skills, and professional experience in bioinformatics and population genomics.

The live version of the site can be found at: [https://no1berg.github.io](https://no1berg.github.io)

## Features

* **Responsive Design:** The site is fully responsive and works on all devices.
* **Modern UI:** A clean and modern user interface, built with Bootstrap.
* **Project Showcase:** A dedicated projects page to highlight my work.
* **Interactive Elements:** Subtle hover effects and modals for a more engaging user experience.

## Built With

* **HTML5**
* **CSS3**
* **Bootstrap 5**
* **Font Awesome** (for icons)

## Getting Started

To get a local copy up and running, follow these simple steps. Don't know why you'd want it though :D

### Prerequisites

You'll need a web browser to view the files locally. No special software is required.

### Installation

1.  Clone the repo:
    ```sh
    git clone [https://github.com/no1berg/no1berg.github.io.git](https://github.com/no1berg/no1berg.github.io.git)
    ```
2.  Navigate to the project directory:
    ```sh
    cd no1berg.github.io
    ```
3.  Open `index.html` in your web browser to view the site.
